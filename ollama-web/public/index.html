À propos

Ollama Web est une interface légère (0 dépendance) qui parle à l’API d’Ollama, exactement comme le fait ollama run sur votre machine — sauf qu’ici le serveur peut vivre dans le cloud, gratuitement.

Trois façons de l’utiliser

  1. Ollama Cloud : les modèles tournent chez Ollama, clé gratuite sur ollama.com/settings/keys.
  2. Ollama distant : un Ollama lancé sur Colab / un VPS / votre PC, exposé par un tunnel (Cloudflare Tunnel, ngrok…).
  3. Ollama local : le site tourne sur la même machine que votre Ollama.

Les discussions restent dans votre navigateur (localStorage) : rien n’est stocké côté serveur.
